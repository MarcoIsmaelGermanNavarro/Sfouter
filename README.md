# Sfouter - Football Scouting Analytics

Plataforma técnica diseñada para la centralización y profesionalización del proceso de scouting en clubes de fútbol. Sfouter permite la gestión de informes de rendimiento de jugadores, eliminando la dispersión de datos y facilitando el seguimiento evolutivo de los deportistas.

##  Despliegue
- **URL de la aplicación:** [https://sfouter-production.up.railway.app/index.php]
